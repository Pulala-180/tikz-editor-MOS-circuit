# Gemini 电路图差异审查提示词

请同时接收两张图：
- 图 A：原始电路图 / 参考截图；
- 图 B：TikZ 导出渲染图。

请只做“差异审查”，不要重画整张图。输出一张 Markdown 差异表，逐项覆盖：

1. **元件清单**：数量、类型（nMOS/pMOS/R/C/电流源/电压源）、标签是否一致；
2. **每个 MOS 的方向**：G/D/S 端口相对位置是否与原图一致；
3. **端口坐标与连接**：每个节点的实际连接元件是否一致；
4. **对称性**：差分对、电流镜、交叉耦合对是否关于中轴/镜像线对齐；
5. **电源与地**：VDD/GND 轨位置、分支接入点、悬垂长度；
6. **走线**：是否正交、是否存在不必要交叉、交叉处上下关系是否合理；
7. **节点黑点与端子**：黑点数量、空心端子数量、位置是否一致；
8. **文字**：标签、字体大小、上下标是否正确；
9. **重叠与遮挡**：元件/文字是否重叠，CL 电容、输出节点是否清晰；
10. **可微调性**：从结构上判断哪些元件应该能单轴滑动，图 B 是否具备该结构；
11. **bus 路由与热区**：交叉反馈/长距离走线是否走命名 bus 折线、是否绕过元件本体、bus 不可见热区是否遮挡其他元件的拖拽热区。

每个差异给出：
- 严重度：`critical` / `major` / `minor` / `cosmetic`；
- 位置描述；
- 建议的 JSON 网表或 TikZ 修改方向。

最后给出结论：
- 是否达到“以图 B 为最终编辑器画布”的可用标准；
- 未达到时，只列出必须修改的 critical + major 项。
